# v0.2.5 — Named host picker for security maintenance

Configure the hosts used for a weekly security maintenance run under **Settings → Devices & services → PatchMon → Configure → Automatic security updates**.

Choose hosts in four groups. Their execution order is Proxmox first, standard hosts, critical hosts, then PBS. Within each group, hosts are listed by friendly name. Selection is **opt-in only**; newly discovered PatchMon hosts never become automatic update targets on their own.

The `patchmon.security_maintenance` action can now omit `host_ids` to use the saved selection. `mode: install` still must be set explicitly and backup gates remain required for the scheduled example. If no hosts were selected or a selected host disappears from the integration inventory, the action rejects the call before installing anything. Supplying explicit `host_ids` continues to override the saved selection for manual runs.

See `docs/examples/weekly_security_automation.yaml` for a weekly Sunday 03:50 example with PBS/VZDump gates and a 20-minute verification wait. Leave it disabled until the template sensors and host choices are validated. OPNsense/unsupported package managers should not be selected.
