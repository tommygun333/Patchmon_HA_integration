# PatchMon Home Assistant v0.2.4 — repository cleanup and reporting docs

- Fixed hassfest manifest field order: `domain`, `name`, then alphabetical keys.
- Added `CONFIG_SCHEMA = cv.config_entry_only_config_schema(DOMAIN)` for the existing `async_setup` registration.
- Removed committed `*.bak`, `__pycache__` and `.pyc` artifacts. `.gitignore` now prevents their accidental return. The source history remains available in Git.
- Updated the main README and `docs/security-maintenance.md` to document the **current** security-maintenance workflow, dashboard attention/report history, backup gating, service health, and restart reconciliation. Supersedes the original validation-only/unattended-upgrades proposal.
- Added copyable examples under `docs/examples/` for the attention/viewer/host cards, standalone service calls, and a **disabled-by-default** weekly 03:30 automation.
- Repaired isolated tests for the aiohttp WebSocket exports, the coordinator's `host_cleanup` import, and the update entity's `removed_host_ids` test double; added approval endpoint testing.
- Added persistence/workflow regressions and repository hygiene assertions. CI now checks report-card JavaScript syntax.

No PatchMon server or agent changes; no automated update schedule is enabled by this release.
